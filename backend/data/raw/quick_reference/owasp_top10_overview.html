OWASP Top 10 2021 快速概览

本文档用于测试 HTML 加载与清洗效果，正文内容为原创整理。

A03:2021 注入（Injection）

注入类漏洞包括 SQL 注入（CWE-89）、命令注入（CWE-78）、 跨站脚本（CWE-79）等，核心问题是不可信输入被当作代码或查询结构执行。

A10:2021 服务端请求伪造（SSRF）

SSRF（CWE-918）允许攻击者控制服务端发起的内网请求， 常见于 URL 预览与回调功能。

修复原则

// 示例：SQL 注入修复
PreparedStatement ps = conn.prepareStatement(
    "SELECT * FROM users WHERE id=?");
ps.setString(1, userId);
