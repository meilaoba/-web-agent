Web 安全快速检查清单（Phase 1 测试用）

一、输入验证
- 所有外部输入（参数、请求体、请求头、文件）都被视为不可信
- 长度、类型、字符集进行白名单校验

二、注入防护
- SQL：使用参数化查询，禁止字符串拼接 SQL
- 命令：禁止 shell 拼接执行，使用参数列表方式
- XSS：输出按上下文转义，前端避免 innerHTML

三、访问控制
- 每个敏感接口做服务端权限校验（不依赖前端隐藏）
- 资源访问校验归属，防止 IDOR 越权

四、会话管理
- Session ID 随机化，Cookie 设置 HttpOnly / Secure / SameSite
- 登录失败限速，会话超时与失效

五、数据保护
- 密码使用 bcrypt/argon2 加盐哈希存储
- 敏感数据加密传输（TLS）

六、文件与上传
- 上传文件做扩展名 + 内容魔数双重校验
- 文件存储于 Web 目录之外并随机化命名

CWE-89 SQL 注入是 Web 安全审计中最高频的漏洞类型之一。
